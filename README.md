# Weblog Website
A modern blog website frontend built using HTML5 and CSS3.

## Overview
Weblog is a blog website frontend designed
to present articles, featured content, and
blog updates in a clean and organized layout.

## Features
- Website header with logo and navigation menu
- Hero image slider
- Featured blog posts section
- Main blog content area
- Newsletter subscription section
- Social media follower widgets
- Recent posts section
- Multi-column footer

## Technologies Used
- HTML5
- CSS3

## Project Structure
- index.html — Main webpage
- style.css — Website styling
- images/ — Website images and assets

## Getting Started
1. Clone this repository.
2. Open the project folder.
3. Open index.html in your browser.
